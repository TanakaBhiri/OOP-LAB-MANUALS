# Lab 08: Collections and Generics

## Objective

The objective of this lab is to work with Java collections and generic methods, and to process lists and text data using reusable algorithms.

## Selected Exercises

### 1. Basic Exercise — Integer List

Created a list of integers and practised adding, accessing, and processing collection elements.

### 2. Intermediate Exercise — Word Frequency

Created a word-frequency program that counts how often words occur in input text.

### 3. Challenge — Generic Bubble Sort

Created a generic bubble-sort implementation that can sort values of a supported type.

## Files

- `Ex1_IntegerList.java`
- `Ex4_WordFrequency.java`
- `Ex5_BubbleSortGeneric.java`

## Concepts Demonstrated

- Collections and `List`
- Iteration over collections
- Maps and frequency counting
- Generics
- Reusable algorithms
- Comparisons and sorting

## Requirements

- JDK 17 or later is recommended.
- A terminal or Java IDE such as IntelliJ IDEA, Eclipse, or VS Code.

## How to Compile and Run

Open a terminal in this lab folder. Compile the source file for the exercise you want to run, then run the class containing `main`:

```bash
javac Ex1_Example.java
java Ex1_Example
```

Replace the example filename and class name with the actual ones for the exercise. Some exercises define helper classes in the same source file. Run exercises separately, since different exercises may use classes with the same name.

## Conclusion

This lab provided practice using collections to manage groups of values and generics to write algorithms that can work with multiple data types.
