# Lab 10: File Handling

## Objective

The objective of this lab is to read and write text files, analyse file contents, and generate reports from stored data.

## Selected Exercises

### 1. Basic Exercise — Save Lines

Created a program that saves lines of text to a file and reads the saved content.

### 2. Intermediate Exercise — File Statistics

Created a program that reads a file and calculates statistics such as line, word, and character counts.

### 3. Challenge — Band Reports

Created a program that reads learner data, groups learners into grade bands, and writes separate report files.

## Files

- `Ex1_SaveLines.java`
- `Ex3_FileStats.java`
- `Ex5_BandReports.java`

## Concepts Demonstrated

- File input and output
- Reading and writing text
- File paths
- Exception handling for I/O
- Text processing
- Grouping data and generating reports

## Requirements

- JDK 17 or later is recommended.
- A terminal or Java IDE such as IntelliJ IDEA, Eclipse, or VS Code.

## How to Compile and Run

Open a terminal in this lab folder. Compile the source file for the exercise you want to run, then run the class containing `main`:

```bash
javac Ex1_Example.java
java Ex1_Example
```

Replace the example filename and class name with the actual ones for the exercise. Some exercises define helper classes in the same source file. Run exercises separately, since different exercises may use classes with the same name.

## Conclusion

This lab demonstrated how Java programs can persist information in files, analyse stored text, and generate useful output reports.
