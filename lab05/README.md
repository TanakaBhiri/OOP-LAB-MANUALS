# Java OOP — LAB05

## Overview

Method overloading, inheritance with interns and payroll, and payment processing using object-oriented design.

## Exercises

- `Ex1_OverloadPrint.java`
- `Ex3_PayrollIntern.java`
- `Ex5_PaymentProcessor.java`

## Requirements

- Java Development Kit (JDK) installed.
- A terminal or Java IDE such as IntelliJ IDEA, Eclipse, or VS Code.

## Compile and run

Open a terminal in this folder. Compile the Java file you want to run:

```bash
javac FileName.java
```

Then run the class containing `public static void main(String[] args)`:

```bash
java ClassName
```

Replace `FileName.java` and `ClassName` with the appropriate source filename and class name. If an exercise uses more than one class, compile the required source files together or compile the main file and let `javac` resolve its dependencies.

## Notes

- Each exercise is kept in its own Java source file where provided.
- Run each exercise separately unless its code explicitly depends on another class in the same folder.
- These are lab exercises for practicing Java object-oriented programming concepts.
